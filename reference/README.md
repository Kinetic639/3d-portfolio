# Historical reference applications

These directories are preserved research material, not workspace members:

- `portfolio-prototype/`: original proof of concept, including uncommitted experiments preserved during relocation.
- `old-new-portfolio/`: the former standalone Next.js application.
- `project-docs/`: historical prototype plans and inventories. These are not current architecture decisions.

Do not import, copy implementations, copy dependency lists, or publish assets from these applications into the active workspace. Read them only to understand visuals, behavior, experiments, and performance lessons. Rebuild behavior independently.

Each reference application retains its original configuration and lockfiles. Relocation preserves source and assets; historical development commands and caches may need separate maintenance before running again. Reference apps are never started, installed, tested or built by root commands.
